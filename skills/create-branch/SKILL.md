# Создание ветки

1. Прочитай [references/branch-naming.md](references/branch-naming.md). Если пользователь задал имя ветки, используй его без переименования; иначе выбери имя по соглашению для задачи пользователя.
2. Проверь допустимость имени через `git check-ref-format --branch`.
3. Проверь, существует ли локальная ветка с выбранным именем. Если имя занято, сообщи об этом и не перезаписывай существующую ветку.
4. Определи базу: по умолчанию текущий HEAD; если пользователь указал другую базу, проверь, что Git может однозначно разрешить её в коммит. При недоступной или неоднозначной базе сообщи причину, не заменяя её текущим HEAD.
5. Создай ветку с переключением через `git switch -c`, передав указанную пользователем базу как начальную точку. Наличие незакоммиченных изменений само по себе не препятствует операции; не делай автоматически commit или stash ради переключения.
6. Проверь результат и сообщи имя активной ветки и фактическую базу, от которой она создана, включая хеш коммита базы.

Если Git не позволяет создать ветку или переключиться на неё, сообщи причину. Не применяй принудительное переключение или сброс изменений.
