# Создание скила

Перед созданием скила прочитай [references/agentskills.md](references/agentskills.md), открой все перечисленные там страницы и изучи их содержимое.

После изучения документации создай скил по запросу пользователя, соблюдая спецификацию Agent Skills и применяя рекомендации по структуре, инструкциям и описанию для активации.

Если какая-либо страница недоступна, сообщи, какую документацию не удалось прочитать. Не утверждай, что изучил её, и явно укажи ограничения при дальнейшей работе.
