# Создание скила

Перед созданием скила прочитай [references/agentskills.md](references/agentskills.md). Изучи обязательные страницы, остальные открывай по указанным условиям.

## Порядок работы

1. Определи по запросу и доступным материалам, какие задачи должен решать скил, когда включаться и какой результат давать. Используй реальные примеры, правила проекта и поправки пользователя; спрашивай только о существенных пробелах, которые нельзя устранить изучением контекста.
2. Создай скил, соблюдая спецификацию Agent Skills. В `description` укажи назначение и условия активации. В инструкциях закрепи полезный повторяемый порядок работы и конкретные правила из исходных материалов, не добавляя общих советов ради объёма. Дополнительные файлы создавай только при необходимости и указывай, когда их читать или использовать.
3. Проверь результат по критериям готовности ниже и исправь найденные проблемы.

## Критерии готовности

- Frontmatter соответствует спецификации, `name` совпадает с именем каталога, относительные ссылки ведут к существующим файлам. Используй доступный валидатор формата; если его нет, проверь эти требования вручную.
- Подобраны пример запроса, где скил должен включаться, и близкий запрос, где он не нужен; `description` позволяет различить их.
- Для сложного скила проверь выполнение на представительной задаче в пределах доступных разрешений и ресурсов. Если такая проверка невозможна, укажи, что осталось непроверенным.
- В итоговом сообщении укажи расположение скила и выполненные проверки. Отличай предложенные сценарии от фактически выполненных проверок; не выдавай проверку формата за проверку поведения.

Если какая-либо страница недоступна, сообщи, какую документацию не удалось прочитать. Не утверждай, что изучил её, и явно укажи ограничения при дальнейшей работе.
